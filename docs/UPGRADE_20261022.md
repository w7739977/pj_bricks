# 2026-10-22 角色和手感升级

## 1. 角色美术

20 个原创果蔬角色重绘为统一的 Q 版精灵画。首版细节过多，按反馈进一步改成圆润比例、大脸、小手脚、粗轮廓和简化色块，随后按“旧版表情更生动”的反馈融合两版，当前启用 expressive-v4 素材，具体方向见 docs/art/EXPRESSION_DIRECTION.md。参考 PokéBonk 的精灵表现与画面层次，没有使用其素材、角色或源码。生成工具：内置图像生成；生成提示保存在 docs/art。

运行时仍使用 20 个独立透明 PNG，沿用 SVG 外壳、索引与中文标签，保持关卡和存档兼容。原素材保留，运行时不加载完整图集。角色采用简化卡通色块；显示时保留默认平滑缩放，避免小尺寸锯齿。

角色使用现有静态画面配合轻微上下移动、放大和挤压；这不是已绘制多帧表情或骨骼动画。未加入会改变实际碰撞面积的效果。

## 2. 拖拽

按下立即抬起；沿用原有抓取偏移和单合成层跟随。移动跨格后检查可匹配目标并描边。受阻时挤压角色，合法几何边界仍由原规则处理；松手吸附为 120ms。中断拖拽时清理按下、阻挡与匹配提示。

之前的 iOS 边缘留白、防选中文字、取消与失焦处理保留。系统级浏览器边缘导航仍不能保证完全被网页拦截。

## 3. 消除和声音

消除从 440ms 改为 240ms。每个元素使用 8 个星点，取消运行时四块角色碎片的复制。连续 2.3 秒内的消除音调逐步升高，上限 5 档。

新增可关闭、记忆设置的本地合成音效。仅在交互后创建 AudioContext；音频不可用或存储受限时不影响游戏。不加载音频文件或外部服务。

## 4. 性能和验证边界

保持原生 DOM/CSS 与整链合成层，没有引入新引擎或运行时依赖。每 7 个角色中仅 1 个有轻微待机动画，拖动时暂停，减少动态画面。遵循系统减少动态效果设置。

自动回归测试与素材隔离检查见 TEST_RESULTS.txt。当前环境没有浏览器二进制，浏览器安装下载失败，因此未完成浏览器布局、触摸输入、帧率和 iPhone 真机验证；请先部署测试，不能把自动测试结果视为真机手感验收。

启动：node server.js。按站点根目录部署 dist；无需 npm install 或编译。
