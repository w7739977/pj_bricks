# 难度增长与奖励重排 · 2026-11-08

目标：仅用每关赠送道具时，首次需要重试或额外救局在第 10 关附近；15–20 关通常需要额外道具。仍允许高手不用额外道具过关，不制造死局、不改变正确的死局搜索规则，也不把广告作为强制通关门槛。

“首次需要救局”按一轮连续闯关遇到的第一次失败统计。产品继续保留重试本关和当前关卡存档，不会失败就清空进度。因为可以重试，本指标不是玩家永久无法超过的最高关卡。

## 校准结果

校准组：25 档关卡 × 200 局 = 5,000 个单关样本。独立种子验证组：20 档 × 200 局 = 4,000 个单关样本，种子偏移 777。前五关为固定盘面的不同选招样本，后续为不同盘面种子。

模拟策略只读取当前棋盘，优先直接消除，否则随机选择合法拖动，不预知未来。根据独立单关成功率合成连续闯关存活曲线，额外重排只在免费次数耗尽、真死局时使用。提示不影响能枚举所有合法动作的自动策略，因此以下不是普通玩家通关率，也不是广告转化率。

均值分别在第 25、20 关截断；仍存活的尾部计入第 26、21 关，未声称已求出无穷关卡的精确数学期望。道具场景假设每次需要时都能领取一次奖励；真实广告的无填充、取消和 SDK 错误会降低实际救局比例。独立验证组与校准组接近，满足首版“10 关左右”的自动策略基准。正式上线后需用真人首次卡关分布继续调整。

## 广告扩展行为

未接入真实广告平台时，不显示观看广告入口，不提供假广告倒计时、不自动赠送奖励。已实现可注册适配器的接口，真实 SDK 报告广告可用后，仅在本关免费重排耗尽且陷入真死局时显示“观看广告，重排一次”。每次尝试每关最多奖励一次，成功后立即使用该次重排救局。

取消、只关闭广告、SDK 错误、重复点击、超出次数，以及重试/切关后的迟到回调均不会发奖。只有 SDK 的 earned-reward 结果才可发奖。真实平台选择、SDK 加载和真实广告验收尚未完成。

本地 Chrome 用第 9 关种子 189 实际操作 52 次消除到 36 枚真死局。明确标注的本地测试替身依次返回取消、完成：取消后棋盘完全不变、重排仍为 0；完成后仅重排一次，棋子多重集和数量不变，且重新有合法消除。测试替身未写入生产代码。

首次测试发现原生 dialog 的旧 close 事件可能在重开后到达，导致取消广告时误重试；已修正并补充异步事件回归测试，修正后重跑同一盘面验证通过。共 127 项自动测试通过，包括开局公平性、奖励上限、迟到回调和广告取消分支。

精简统计见 difficulty-balance-summary.json；完整原始样本保存在本次测试输出目录。本次改动需部署后才在线上生效。
