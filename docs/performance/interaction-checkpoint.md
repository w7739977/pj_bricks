## 接续入口

1. 在仓库根目录运行 `LAB_HOST=0.0.0.0 npm run test:perf`。Mac 打开 `http://127.0.0.1:3014/demo`。同一 Wi-Fi 下，iPhone Chrome 打开 Mac 局域网 IP 的 3014 端口和 `/demo`。
2. iPhone 使用同一开局，复测快速两次消除、点按轻微偏移、长链回弹和撞边反向。面板保存 JSON，报告需注明机型和 iOS 版本。
3. 用 Demo 的「预跟随」按钮做同机同盘对照，每组每类至少 10 次。检查首个位移、误锁轴、拖动 P95 和松手峰值，尤其留意轻触是否显得误拖。根据报告决定预跟随参数和是否放入正式页。
4. 用私有手机测试页验证首次有效拖动。真人样本到位后，复核第 10 关附近的首次救局与第 15–20 关道具使用。

若额度或会话将中断，把最后一个通过的验证、复现命令和下一项待办补到本文件。恢复时先读本文件和 `git status --short`，从首项未验收的工作继续。
